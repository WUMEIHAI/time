# 时间计算器

一个纯前端、单文件的时间偏移计算工具：以**当前时间**为基准，向前（增加）或向后（减少）推移指定的**天 / 小时 / 分钟 / 秒**，得到目标时刻。

- **项目类型**：静态网页（HTML + CSS + 原生 JavaScript）
- **入口文件**：`index.html`
- **依赖情况**：无任何第三方库、无 CDN、无构建步骤、无后端接口
- **运行方式**：双击 `index.html` 用浏览器打开即可，**完全离线可用**

---

## 项目简介

日常经常需要快速换算"N 天 X 小时之后是几月几号几点"——比如计算倒计时截止时刻、推算保修到期时间、确认任务 deadlines。手算既要处理进位又要考虑月份天数，很麻烦。

本工具把这件事简化成一个表单：选「增加 / 减少」，填四个数值，点一次按钮，直接给出结果时间点。顶部还带一个每秒刷新的**实时当前时间**显示，方便对照。

核心逻辑：

```
偏移毫秒数 = 天 × 86400000 + 小时 × 3600000 + 分钟 × 60000 + 秒 × 1000
目标时间   = 当前时间 ± 偏移毫秒数
```

所有计算都在浏览器本地完成，**不上传任何数据，也不发起网络请求**。

## 功能说明

### 界面组成

| 区域 | 说明 |
|---|---|
| **实时时钟** | 顶部显示当前时间，每秒自动刷新一次（`setInterval` 1000ms） |
| **操作选择** | 下拉框：`增加`（向未来推） / `减少`（向过去推） |
| **数值输入** | 天、小时、分钟、秒 四个文本框，默认占位符 `0` |
| **计算 / 重置** | 底部两个并排按钮 |
| **结果区** | 显示「计算后的时间: …」 |

### 主要特性

- **实时时钟**：页面顶部时间每秒跳动，基于设备本地时间。
- **双向偏移**：同一组输入，切换「增加 / 减少」即可得到未来或过去的时间点。
- **输入实时校验**：用正则 `^\d*$` 逐字符校验，只允许数字；输入非法字符时立即**自动剥离**并短暂显示红色提示。
- **空值容错**：留空的输入框按 `0` 处理，不必填满四项即可计算。
- **占位符智能切换**：输入框聚焦时隐藏 `0` 占位符，失焦且为空时恢复，避免视觉干扰。
- **一键重置**：清空所有输入、恢复占位符、隐藏错误提示、操作回到「增加」、清空结果。
- **单文件零依赖**：HTML、CSS、JS 全在一个文件里，**无 CDN 外链**，断网也能正常用。

### 输入校验规则

| 输入 | 处理方式 |
|---|---|
| 纯数字（如 `12`） | 正常通过 |
| 留空 | 按 `0` 计算 |
| 含字母（如 `12a`、`a12`） | 提示错误，剥离字母保留数字 |
| 小数（如 `1.5`） | 提示错误，剥离小数点 → 变成 `15` |
| 负数（如 `-5`） | 提示错误，剥离负号 → 变成 `5` |

> ⚠️ 校验逻辑是**剥离非法字符**而非拒绝输入。因此 `1.5` 会静默变成 `15`、`-5` 会静默变成 `5`。填写后请留意输入框中实际留下的数字。

## 使用方法

### 打开方式

直接双击 `index.html`，或右键用任意现代浏览器打开。无需安装、无需联网、无需本地服务器。

若需通过 HTTP 访问（例如手机在同一局域网调试）：

```bash
# Python 3
cd D:\time
python -m http.server 8000
# 浏览器访问 http://localhost:8000

# Node.js
npx serve .
```

### 操作步骤

以**计算「1 天 2 小时 30 分钟后」的时刻**为例（假设当前为 2026-09-14 09:00:00）：

1. 操作选择保持「增加」
2. 「天」填 `1`，「小时」填 `2`，「分钟」填 `30`，「秒」留空（自动按 0）
3. 点击「计算」

结果区显示：`计算后的时间: 2026/9/15 11:30:00`

再举一例：**回推 90 天**——操作选「减少」，天填 `90`，其余留空 → `2026/6/16 09:00:00`。

### 重置

点击「重置」清空全部输入与结果，重新开始。

## 注意事项

1. **基准是"点击计算的那一刻"**：结果是一个**时间快照**，不会随时间自动变化。顶部实时时钟在走，但结果区不会跟着更新，需要重新点「计算」。
2. **按固定时长偏移，不是日历运算**：「增加 30 天」= 加 30×24 小时，**不等于日历上的"一个月后"**（月份有 28~31 天不等）。需要精确的"几个月后""几年后"请用日历工具。
3. **填写上限约 1 亿天**：超出 JavaScript `Date` 可表示范围（约 ±1 亿天 / ±27 万年）后，结果会显示 `Invalid Date`。正常使用场景不会触及。
4. **小数与负数会被静默改写**：如前述，`1.5` → `15`、`-5` → `5`。本工具只接受**非负整数**，需要减少时间请用「减少」选项，不要在数值里加负号。
5. **时间显示格式依赖系统区域设置**：输出用 `toLocaleString()`，格式随浏览器/系统语言地区变化（例如中文环境常见 `2026/9/14 09:16:09`，其他环境可能是 `9/14/2026, 9:16:09 AM`）。
6. **时区取设备本地时区**：不做时区转换，跨时区协同时需自行换算。
7. **数据不保存**：刷新页面后输入与结果都会清空，没有做本地持久化。
8. **浏览器兼容性**：使用了模板字符串、箭头函数、`forEach` 等 ES6 特性，建议使用近两年的 Chrome / Edge / Firefox / Safari。

## 二次开发提示

- 计算主逻辑在 `calculateTime()` 函数里，改换算规则只动这一处。
- 输入校验在 `validateInput(fieldId)`，错误提示元素按 `${fieldId}-error` 命名，新增字段需同步添加对应的输入框与提示 div。
- 实时时钟由 `updateCurrentTime()` + `setInterval` 驱动，刷新间隔在 `window.onload` 中设置为 1000ms。
- 所有样式集中在 `<head>` 的 `<style>` 内，配色直接写在规则里（主色 `#007BFF`、重置按钮 `#6c757d`），改主题需逐条替换。
- 已知小瑕疵：顶部时钟元素 `<div id="currentTime" class="result">` 同时使用了 `result` 类，会继承该类的 `margin-top: 20px` 与 `font-weight: bold`（`font-size` 与 `color` 已被 ID 规则覆盖）。如介意可移除该类。
